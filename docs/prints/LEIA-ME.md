# Capturas de tela

O arquivo `00-previa-local-ilustrativa.png` é uma prévia local da interface. Ele não foi capturado do endereço publicado.

Adicione nesta pasta as capturas reais feitas no navegador, por exemplo:

- `01-tela-inicial.png`
- `02-formulario-cadastro.png`
- `03-edicao-criatura.png`

No macOS, use `Command + Shift + 4`, selecione a área da página e salve os arquivos nesta pasta.
